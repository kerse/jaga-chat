# JAGA.CHAT — Мобильный прототип

Интерактивный мобильный прототип чатов с концепцией пространств (JAGA Хаб + пространства учителей) и каналов.

## Демо
👉 [Открыть онлайн (GitHub Pages)](https://kerse.github.io/jaga-chat/)

## Стек технологий
- HTML5
- CSS3 (модульная структура, переменные, анимации)
- Vanilla JavaScript (без фреймворков и сторонних библиотек)
